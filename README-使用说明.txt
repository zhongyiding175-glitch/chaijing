精读 · 查经  v1
================

怎么用（手机）：
1. 把整个文件夹解压到手机里（例如 内部存储/查经/）
2. 用 Chrome / Edge / 夸克 等浏览器打开里面的 index.html
3. 点任意一节经文，右侧（手机上在下方）会列出这节的全部资料

资料包含：
  · 经文        和合本
  · 逐节注解    基督徒文摘解经系列（原文字义 / 文意注解 / 灵意注解 / 话中之光）
  · 原文逐词    信望爱和合本，带 Strong 编码
  · 原文词条    CBOL 原文工具书（希腊文 6062 条 / 希伯来文 8864 条）
  · 整章资料    圣经各卷要义、陈终道新约书信读经讲义
  · 主题        App 内置主题索引

全程离线，不联网，不调用任何 AI 模型，零费用。
